# 项目范围与开发边界

## 唯一开发主线

本仓库是 Quasi-Steady-State Lap Time Simulation 的唯一持续开发项目。`reference/` 中的报告和旧项目均为冻结快照：不直接加入 MATLAB 路径、不在原目录继续开发，复用资产必须迁移到主项目并补齐单位、坐标、接口和测试。

## 已冻结的不变量

1. 内部物理量采用 SI 单位；车辆坐标为 `X` 前、`Y` 左、`Z` 上。
2. 固定赛线通过 `TrackData` 离散表示，闭环最后一段必须显式参与传播与时间积分。
3. QSS/GGV 轮胎包络与 7DOF `slip_force` 本构是两个独立接口。
4. 理论 GGV 的纵向载荷转移使用固定点求解，不使用 `ax=0` 的静态近似代替。
5. 外部轮胎 evaluator 必须声明 schema、坐标、轮胎侧、有效域和错误策略，禁止静默 fallback。
6. Motion Ratio 的 CSV 定义已经冻结；轮荷到 jounce 的垂向平衡尚未定义，因此悬架 lookup 不改变当前 GGV。

## 版本边界

- V0.1：固定赛线、常数 μ、前向/后向传播和解析定半径基准。
- V0.2：四轮轮荷、纵横载荷转移、气动和抬轮诊断。
- V0.3：载荷敏感轮胎与 combined-slip 包络。
- V0.4：动力、扭矩、功率、最高车速、制动偏置与机械约束。
- V0.5：外部 GGV 读取、速度相关残差校准和校准报告。
- V0.6：单参数 Sensitivity 与多参数 DOE。
- V0.7：离线 Simscape 悬架几何 lookup 接缝。
- V0.8：7DOF 加速、制动、定半径关键事件验证。
- V0.9：高级轮胎稳态代数适配器契约及 placeholder。
- V1.0：解析 regression、数值 benchmark、完整 limiter/DOE 报告、可复现实验和文档冻结。

## V1.0 支持范围

- 固定赛线 QSS 圈速和周期速度传播；
- 常数 μ 或概念级载荷敏感轮胎包络；
- 四轮法向载荷、气动、RWD/FWD/AWD 驱动约束和制动偏置；
- 理论 GGV，或基于外部能力表的速度相关残差缩放；
- 单参数敏感性、全因子 DOE 和距离加权 limiter 报告；
- 7DOF 的直线加速、直线制动和定半径事件级一致性检查；
- MF/UniTire 等外部稳态代数轮胎模型的严格适配契约。

## 验证声明分级

1. **解析验证**：存在独立公式参考，可作为 correctness regression。
2. **实现一致性验证**：比较对称性、离散网格、共享能力包络或重复运行，只说明软件行为自洽。
3. **外部物理验证**：需要实车、轮胎台架或独立高保真模型证据。

当前 V1.0 完成前两级，没有完成第三级。`simple_track` 圈时、synthetic GGV 校准、DOE 排名和共享包络的 7DOF 对比不得称为实车预测精度。

## 不在当前范围

- 自由赛线优化、driver model、全赛道瞬态求解；
- raw log 到 GGV 的识别和不确定性量化；
- 已验证的真实 Magic Formula / UniTire evaluator 与参数；
- 能耗、热模型、坡度、横坡、路面空间 μ；
- 悬架弹簧/阻尼垂向平衡、在线 Simscape 联算；
- 对实车圈速绝对误差的承诺。
