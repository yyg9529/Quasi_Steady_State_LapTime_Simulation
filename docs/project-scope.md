# 项目范围与开发边界

## 唯一开发主线

本仓库是 Quasi-Steady-State Lap Time Simulation 的唯一持续开发项目。

`reference/` 中的研究报告和旧项目均为冻结快照：

- 不在原目录内继续开发、修复或重构。
- 不直接把旧项目加入 MATLAB 运行路径。
- 不让主求解器在运行时依赖旧项目文件。
- 复用内容必须迁移到主项目对应模块，并补充单位、坐标、接口和测试说明。

## Phase 0：接口冻结

编写核心求解器前，至少需要确认：

1. 项目内部坐标系、转角正方向和四轮编号。
2. 全部物理量的 SI 单位约定。
3. `TrackData`、`VehicleParams`、`TireParams`、`AeroParams`、`SolverOptions` 和 `LapResult` 的字段。
4. Motion Ratio 定义及轮端/减振器端换算关系。
5. 轮胎模型输入输出、有效域和越界行为。
6. 固定赛线 MVP 的定量验收标准。

接口冻结前允许进行资产盘点和独立验证，不允许各模块自行形成互不兼容的参数接口。

## 版本边界

- V0.1：固定赛线、点质量模型、基础轮胎极限、前向/后向速度传播。
- V0.2：两轨载荷转移、驱动与制动约束、四轮法向载荷。
- V0.3：载荷敏感轮胎和 combined-slip 包络。
- V0.4：悬架 lookup、camber/toe/Motion Ratio 集成。
- V0.5：动力系统细化、能耗、参数扫描和 CI 固化。
