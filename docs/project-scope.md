# 项目范围

## 工程目标

本项目实现固定赛线 QSS 圈速求解：由离散赛道、车辆、轮胎、气动、组合动力系统和制动模型在线生成 GGV，沿已知赛线传播速度约束，输出圈时、速度剖面、约束归因、单圈能量和耐久容量估算。用途是 Formula Student 早期方案的相对筛选、参数敏感性与 DOE，而不是宣称实车绝对精度。

## 当前范围

- 闭环或开环固定赛线 QSS；闭环积分包含最后一个 `N→1` 段。
- 实际横向加速度（actual Ay）下的纵向能力查询，而不是只在 `Ay=0` 评价动力。
- 四轮法向载荷、载荷转移、载荷敏感轮胎、简化 combined-slip 与气动载荷。
- 组合动力接口下的电机转矩/功率/转速/电压、FSG 规则、电池和逆变器约束。
- `result.limiter` 主约束与 `result.active_constraints` 多约束诊断。
- 单圈能量、按相同最小圈速度剖面重复的耐久容量估算。
- Sensitivity/DOE：直接扫描 `inverter_power_W` 和 `gear_ratio`，不得修改 `rules.*`。
- 结果后处理：赛道速度图、动力/能量图、GGV 曲面图。
- `s_m,x_m,y_m,curvature_1_m,track_width_m` 真实 geometry CSV 的精确弧长闭环读取；真实文件保持 local-untracked，`reference/` 保持本地 Git ignored。

## 明确不在范围内

- 7DOF、14DOF 或全赛道瞬态整车模型；
- 自由赛线和驾驶员模型；
- 瞬态轮胎松弛、完整悬架运动学在线耦合、路面空间变化；
- 瞬态 ODE、dq 电机控制、弱磁和开关级逆变器模型；
- BMS、电芯、内阻、温升/冷却、热降额、SOC/电压动态耦合和回生制动优化；
- 部件布置、动力位置变化以及多电机扭矩矢量分配；
- 在线调用 Simscape 或让悬架 lookup 直接改变 GGV；
- 原始实车日志自动识别 GGV；
- 经试验标定后可用于实车绝对预测的高保真模型。

## 冻结假设

- 固定 DC 电压：正式演示采用固定 600 V 母线电压；
- 电机、逆变器、传动和电池放电采用常数效率；
- 无再生，制动能量不回收；
- 无热状态和热可行性评价；
- 滚阻暂取 `F_rolling=0`；
- 耐久估计重复同一条已求得的最小圈速度剖面；
- 正式演示用 26 圈和 1.10 安全系数，并按可用 SOC 窗口换算标称容量。

上述边界意味着结果可用于同一冻结假设下的相对筛选，不应解释为实车绝对精度或耐久完赛保证。热、电压随 SOC 变化、驾驶员、赛线和环境变化都可能改变结论。
