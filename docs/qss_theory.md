# QSS 理论与适用边界

## 基本关系

固定赛线上，曲率为 `kappa [1/m]`，车辆沿线速度为 `v [m/s]`：

```text
ay_mps2 = v^2 * kappa
ay_g    = ay_mps2 / g
```

GGV 给出指定速度和横向加速度需求下可用的最大加速 `ax_max` 与最大制动 `ax_min`。空间域速度传播采用：

```text
v_next^2 = v^2 + 2 ax ds
```

## V0.1 假设

- 车辆视为点质量，轮胎采用常数 `mu_x/mu_y`；
- 轮胎联合能力由超椭圆近似；
- 赛线、曲率和路面附着已知且不随时间变化；
- 驾驶员瞬时使用全部可用能力，不考虑控制延迟和瞬态轮胎；
- 速度剖面是 flying lap 的周期稳态结果。

在常数 μ 且只约束总轮胎力时，载荷转移只重新分配法向载荷，不会改变 `mu * sum(Fz)`。因此“重心高度或轮距变化必然改变圈速”不是一般事实；只有引入载荷敏感性、驱动/制动轴分配、逐轮 combined slip 或抬轮等机制后才应出现该敏感性。

## 后续耦合

载荷敏感轮胎、RWD/FWD 牵引与制动偏置会造成 `ax ↔ wheel loads ↔ tire capacity` 耦合。对应 GGV 点必须分别对加速和制动求固定点并记录残差，不能继续沿用 `ax = 0` 的轮荷作为最终能力。
