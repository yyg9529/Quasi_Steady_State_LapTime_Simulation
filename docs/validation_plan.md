# 验证计划

## V0.1 门禁

- CSV 读取后 `s` 严格递增、`ds` 为正、曲率单位明确；
- 常数 μ 轮胎力与 `Fz` 线性，`Fz <= 0` 时为零；
- 定半径速度与 `sqrt(mu_y*g*R)` 一致；
- 闭环速度剖面对节点循环移位和初始速度剖面不敏感；
- 每一段同时满足横向、前向加速和后向制动约束；
- 空间积分与恒速/恒加速度解析结果一致；
- 网格加密后圈速收敛。

## 后续门禁

- V0.2：轮荷守恒、纵横载荷转移方向、气动力平方律和抬轮诊断；
- V0.3：载荷敏感性方向、combined-slip 轴端点和连续性；
- V0.4：低速扭矩/高速功率/附着限制与制动偏置；
- V0.5：校准限幅、连续性、缺失实车数据回退和报告；
- V0.6：DOE 每 case 重生 GGV、排序和 baseline 可复现；
- V0.7：悬架断点插值、单位转换、MR 定义差分校验；
- V0.8：7DOF 力/功率符号、低速正则、直线对称性和事件能量检查。

回归测试只锁定经过解析/独立模型验证后的结果，不能把未知正确性的首次输出直接当作真值。
